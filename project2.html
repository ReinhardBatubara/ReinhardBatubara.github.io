DelDeals — Campus Student E-commerce
Class / Course Assignment

Project Evaluation Q&A

1. Project Summary
A web-based e-commerce platform developed specifically for the Del Institute of Technology campus community, enabling students to securely buy and sell items.
2. Project Type
Class / Course Assignment. Created as part of the Web Programming and Web Testing course curriculum.
3. Team & Role
GROUP PROJECT (Team of 4). I served as the Full-Stack Developer responsible for designing the database models, configuring MVC controllers, and integrating user authentication and item posting pages.
4. Key Contributions & Impact
Delivered a functional, secure web platform within a strict 14-week timeline, solving campus transaction needs and enhancing peer-to-peer student transactions.
5. Learnings & Takeaways
Mastered backend development in Laravel, database normalization, database integration, and teamwork coordination using Trello for tracking tasks.

Technologies

PHP, Laravel, MySQL, HTML5, CSS3, JavaScript, Git, Trello.

Key Skills Demonstrated

Model-View-Controller (MVC), Database Normalization, Authentication Security, Agile Iterative Delivery.
